# Яна Буглова — профессиональная визитка

Личный сайт HR-менеджера агентства недвижимости «Сити Центр», дипломированного SMM-специалиста с опытом обучения международному бизнесу в Китае.

Опубликованный сайт: https://yana-buglova-profile.hoglax.chatgpt.site

## Структура

- `dist/index.html` — содержание страницы, биография, образование и контакты.
- `dist/style.css` — оформление и адаптация под разные размеры экрана.
- `dist/app.js` — мобильное меню и копирование email.
- `dist/assets/` — локальные файлы шрифта Manrope и лицензия OFL.
- `dist/favicon.svg` — значок сайта.
- `.openai/hosting.json` — идентификатор и настройки существующего сайта в Sites. Секретов в файле нет.

Сайт состоит из статических HTML, CSS и JavaScript. Установка зависимостей и сборка не требуются.

## Локальный просмотр

Из корня репозитория:

```sh
python3 -m http.server 8000 --directory dist
```

Откройте http://localhost:8000.

## Редактирование

Тексты и адрес для связи находятся в `dist/index.html`. Если email меняется, обновите его также в `dist/app.js` для кнопки копирования.

Цвета и адаптивные стили находятся в `dist/style.css`. Основные цвета задаются CSS-переменными в начале файла.

## Публикация

GitHub хранит исходники проекта. Текущая опубликованная версия размещена в Sites; изменения в GitHub сами по себе её не обновляют. После правок выполните отдельную публикацию в существующий проект Sites с сохранением идентификатора из `.openai/hosting.json`.

## Проверенная версия

Исходная версия проверена в Chromium на ширинах 320, 390, 600, 768, 1024 и 1440 пикселей. Проверены меню, раскрытие описаний сертификатов, ссылки на почту и копирование email.

Сведения о профессиональной подготовке основаны на предоставленных Яной данных и сертификатах.
