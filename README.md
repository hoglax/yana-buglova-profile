# Яна Буглова — профессиональная визитка

Личный сайт HR-менеджера агентства недвижимости «Сити Центр», дипломированного SMM-специалиста с опытом обучения международному бизнесу в Китае.

Сайт: https://hoglax.github.io/yana-buglova-profile/

## Структура

- `index.html` — содержание страницы, биография, образование и контакты.
- `style.css` — оформление и адаптация под разные размеры экрана.
- `app.js` — мобильное меню и копирование email.
- `assets/` — локальные файлы шрифта Manrope и лицензия OFL.
- `favicon.svg` — значок сайта.
- `.nojekyll` — публикация статических файлов без обработки Jekyll.

Сайт состоит из статических HTML, CSS и JavaScript. Установка зависимостей и сборка не требуются.

## Локальный просмотр

Из корня репозитория:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000.

## Редактирование

Тексты и адрес для связи находятся в `index.html`. Если email меняется, обновите его также в `app.js` для кнопки копирования.

Цвета и адаптивные стили находятся в `style.css`. Основные цвета задаются CSS-переменными в начале файла.

## Публикация

Сайт публикуется через GitHub Pages из ветки `main`, папка `/ (root)`. Вход в аккаунт не требуется.

Изменения после сохранения в `main` автоматически запускают публикацию. Обновление обычно требует некоторого времени; состояние публикации можно посмотреть во вкладке Actions или в Settings → Pages.

## Проверенная версия

Исходная версия проверена в Chromium на ширинах 320, 390, 600, 768, 1024 и 1440 пикселей. Проверены меню, раскрытие описаний сертификатов, ссылки на почту и копирование email.

Сведения о профессиональной подготовке основаны на предоставленных Яной данных и сертификатах.
